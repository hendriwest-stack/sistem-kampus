Profil Lulusan

Profil lulusan Program Studi Sistem Komputer

Kode PL Profil Lulusan (PL) Keterangan Sumber Profil Lulusan Profesional / Okupasi Bidang Pekerjaan / Peran
PL 1 Lulusan memiliki sikap profesional, beretika, bertanggung jawab, adaptif, mampu berkomunikasi dan bekerja sama secara efektif, serta memiliki semangat pembelajaran sepanjang hayat, inovasi, dan kewirausahaan dalam pengembangan teknologi Sistem Komputer untuk kemaslahatan masyarakat, industri, dan pemerintah. Sikap Keterampilan Umum Permendikbudristek No. 53 Tahun 2023; KKNI Level 6; APTIKOM Profesional Teknologi Informasi / Digital Technology Professional Industri TIK, perusahaan teknologi, pemerintahan, pendidikan, konsultan teknologi, startup
PL 2 Lulusan memiliki kemampuan untuk menerapkan konsep matematika, sains, dasar komputasi, algoritma, arsitektur komputer, elektronika, dan sistem tertanam dalam menganalisis serta memformulasikan solusi permasalahan di bidang Sistem Komputer. Pengetahuan Permendikbudristek No. 53 Tahun 2023; KKNI Level 6; APTIKOM; ACM/IEEE CE 2016 Computer Engineer / System Programmer / Embedded System Engineer Hardware dan digital systems; programming and software development; IoT; embedded systems; integrasi perangkat
PL 3 Lulusan memiliki kemampuan untuk merancang, mengembangkan, mengintegrasikan, mengimplementasikan, dan mengevaluasi sistem komputer yang melibatkan perangkat keras, perangkat lunak, jaringan komputer, Internet of Things (IoT), sistem tertanam, serta teknologi komputasi cerdas sesuai kebutuhan pengguna. Keterampilan Khusus KKNI Level 6; APTIKOM; Peta Okupasi Nasional Bidang TIK; ACM/IEEE CE 2016 System/Network Engineer; Network Administrator; IoT Engineer; Cloud Computing Engineer Network and Infrastructure; IT Mobility and Internet of Things; IT and Computing Facilities; System Integration
PL 4 Lulusan memiliki kemampuan untuk merancang, mengelola, mengintegrasikan, mengamankan, serta mengembangkan infrastruktur komputasi, jaringan komputer, sistem terdistribusi, komputasi awan, analisis data, dan kecerdasan buatan guna menghasilkan solusi dan inovasi teknologi yang bernilai tambah. Keterampilan Khusus KKNI Level 6; APTIKOM; Peta Okupasi Nasional Bidang TIK; ACM/IEEE CE 2016 Data Engineer; Data Analyst; AI/ML Engineer; Software Engineer; Digital Product Developer; Technopreneur Data Science & Artificial Intelligence; Digital Product Development; Programming & Software Development; IT Services
